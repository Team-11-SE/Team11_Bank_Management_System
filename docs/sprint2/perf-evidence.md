# Sprint 2 performance evidence

Measured on **macOS-26.5.2-arm64-arm-64bit** with `Apple clang version 17.0.0 (clang-1700.6.4.2)`.

Dataset: **10000 accounts**, **100000 transaction lines**, generated by `tests/perf_test.py` (`make perf`).

| Measure | Result | SRS limit | Requirement | Status |
|---|---|---|---|---|
| Start-up: backup + integrity check + load 10000 accounts / 100000 log lines | 0.066 s | <= 2.00 s | BMS-NF-002 | PASS |
| 100 money operations (34 deposit, 33 withdraw, 33 balance), average | 0.0786 s | <= 1.00 s | BMS-NF-001 | PASS |
| 100 mini statements, average | 0.0104 s | <= 1.00 s | BMS-NF-003 | PASS |

Reproduce with:

```sh
make clean
make perf
```

The script prints this file and exits non-zero if any limit is missed.
